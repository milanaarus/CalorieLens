# CalorieVision / CalorieLens

Учебный проект: оценка калорий по фотографии, личный дневник и недельная статистика. Главная страница содержит интерактивную 3D-тарелку.

## Актуальная версия

Текущие исходники находятся в `CalorieVision-source.zip`. Архив содержит читаемые исходные файлы React и FastAPI, инструкции и тесты. Распакуйте папку `CalorieVision` для локальной разработки. Dockerfile извлекает тот же архив и собирает приложение из него.

Папки `frontend` и `backend`, оставшиеся от первоначального коммита, сохранены как история начального каркаса; Docker-сборка их не использует.

SHA-256 пакета: `80270372fa911a749afaa23a099d5f5e7d5bf5df6c58f16c3142e9bfa6603b0d`.

## Размещение на Render

В `render.yaml` указан бесплатный пробный Web Service и бесплатная PostgreSQL в одном регионе. Оплата не требуется для указанных тарифов, но учитывайте текущие ограничения Render: база бесплатного тарифа имеет срок действия, а памяти Web Service может не хватить для PyTorch. Работу распознавания нужно проверить после сборки. Переход на платные ресурсы — отдельное решение владельца.

Секрет авторизации генерируется Render. Личные базы, пароли и `.env` в архив не включены. После запуска проверьте регистрацию, анализ фотографии, запись в дневник и прямое открытие `/login`.
