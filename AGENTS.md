# Workflow requested by the project owner

After each completed and successfully verified change, create a descriptive commit and publish it to https://github.com/milanaarus/CalorieLens. Do not leave successful changes only in local archives. Never commit secrets, personal databases or dependency folders. Verify the remote commit before reporting publication. Report deployment separately from GitHub publication.

Current production build uses the root CalorieVision-source.zip and Dockerfile. Root frontend/backend folders on GitHub are the old scaffold; do not mistake them for the production source. Keep the source archive and README checksum in sync when publishing.
